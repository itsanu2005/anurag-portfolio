# Anurag Yadav — Portfolio Website

A responsive portfolio inspired by the reference screenshot you uploaded. It uses a warm pink, cream, and muted-plum palette, editorial serif headings, section cards, and responsive navigation.

## Run locally
Open `index.html` in a browser. No build tools are required.

## Personalize before publishing
1. Replace the profile placeholder in `index.html` with your own photo, for example:
   `<img src="assets/profile.jpg" alt="Anurag Yadav">`
   Then add CSS for `.portrait-placeholder img` (or replace the placeholder block with the image).
2. Update URLs in `script.js` (`YOUR_USERNAME`, `YOUR_PROFILE`, and project URLs).
3. Put your resume PDF at `assets/Anurag-Yadav-Resume.pdf`.
4. Add only verified certifications, experience, achievements, and course links. The current content uses the details known so far and labels unknown links as placeholders.
5. If you have a deployed demo for each project, add a demo link to the relevant project card.

## Deploy
You can deploy this static folder using GitHub Pages, Netlify, or Vercel. For Vercel, import the folder/repository as a static site; no framework build command is needed.
